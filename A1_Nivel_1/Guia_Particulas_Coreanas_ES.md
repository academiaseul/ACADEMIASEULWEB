# Las partículas básicas del coreano — Guía Academia Seúl (Nivel A1)

Material original de Academia Seúl · Método Chingu™

En coreano, las **partículas** son pequeñas terminaciones que se pegan al final de una palabra para indicar **qué función cumple** en la oración (quién hace la acción, sobre qué hablamos, qué recibe la acción, etc.). No se traducen como palabras sueltas: son "etiquetas" que marcan el papel de cada sustantivo.

Regla de oro que se repite en casi todas: **si la palabra termina en vocal se usa una forma, y si termina en consonante (batchim, 받침) se usa otra.**

---

## 1. 이 / 가 — partícula de SUJETO

Marca **quién o qué realiza la acción** o de quién se predica algo. También sirve para **enfatizar** o **introducir información nueva**.

- Termina en **vocal → 가**
- Termina en **consonante → 이**

**Ejemplos (originales):**

| Coreano | Español |
|---------|---------|
| 날씨**가** 좋아요. | El clima está bueno. |
| 친구**가** 와요. | Viene un amigo. |
| 선생님**이** 바빠요. | El profesor está ocupado. |
| 동생**이** 자요. | Mi hermano menor duerme. |

**Usos clave:**
- Responder "¿quién?": 누구**가** 왔어요? → 민수**가** 왔어요. (¿Quién vino? → Vino Minsu.)
- Enfatizar el sujeto: 준호 씨**가** 준비할 거예요. (Es Junho —y no otro— quien lo va a preparar.)

**Formas irregulares importantes** (con 가):
- 나 + 가 → **내가** (yo)
- 저 + 가 → **제가** (yo, formal)
- 누구 + 가 → **누가** (quién)

---

## 2. 은 / 는 — partícula de TEMA y CONTRASTE

Marca **el tema del que hablamos** ("en cuanto a...", "hablando de..."). Se usa para info ya conocida, para comparar o para contrastar dos cosas.

- Termina en **vocal → 는**
- Termina en **consonante → 은**

**Ejemplos (originales):**

| Coreano | Español |
|---------|---------|
| 저**는** 학생이에요. | Yo soy estudiante. |
| 제주도**는** 섬이에요. | (En cuanto a) Jeju es una isla. |
| 서울**은** 한국에 있어요. | Seúl está en Corea. |
| 김치**는** 매워요. | El kimchi (ese sí) es picante. |

**Contraste (su uso más típico):**
- 형**은** 키가 커요. 그렇지만 동생**은** 키가 작아요.
  Mi hermano mayor es alto. En cambio, mi hermano menor es bajo.
- 사과 있어요? — 아니요, 배**는** 있어요.
  ¿Hay manzanas? — No, pero peras sí hay.

---

## 이/가 vs 은/는 — la duda eterna (explicada fácil)

Ambas pueden acompañar al sujeto, pero **no son lo mismo**:

- **이/가** → señala **quién** hace algo, aporta **información nueva** o enfatiza. Piensa: "¡ESTE es el que...!"
  → 누**가** 선생님이에요? — 제인 씨**가** 선생님이에요.
- **은/는** → presenta el **tema** o **contrasta**. Piensa: "hablando de..."
  → 제인 씨**는** 선생님이에요. (그리고 마크 씨는 학생이에요.)

Truco de clase: si puedes traducir con *"en cuanto a / hablando de"* o hay comparación → **은/는**. Si respondes *"¿quién?"* o es algo nuevo → **이/가**.

---

## 3. 을 / 를 — partícula de OBJETO (complemento directo)

Marca **el objeto que recibe la acción** del verbo (qué comes, qué ves, qué compras...).

- Termina en **vocal → 를**
- Termina en **consonante → 을**

**Ejemplos (originales):**

| Coreano | Español |
|---------|---------|
| 커피**를** 마셔요. | Bebo café. |
| 영화**를** 봐요. | Veo una película. |
| 밥**을** 먹어요. | Como (arroz/comida). |
| 음악**을** 들어요. | Escucho música. |

**Verbos que suelen pedir 을/를:** 먹다 (comer), 마시다 (beber), 좋아하다 (gustar), 읽다 (leer), 보다 (ver), 만나다 (encontrarse con), 사다 (comprar), 가르치다 (enseñar), 배우다 (aprender), 쓰다 (escribir).

**Dos notas útiles:**
- En lenguaje hablado, a veces se omite: 밥 먹어요 (en vez de 밥을 먹어요).
- N + 하다: cuando el objeto va con 하다, se junta en una sola palabra → 공부**를** 하다 = 공부하다 (estudiar); igual 운동하다, 요리하다.
- 무엇 (qué) se abrevia en conversación: 무엇을 → 뭘 → 뭐 해요? (¿Qué haces?)

---

## 4. 와 / 과 · (이)랑 · 하고 — "Y" (unir) y "CON" (compañía)

Sirven para **unir sustantivos** ("A y B") o para indicar **con quién** haces algo. Las tres significan lo mismo; cambia el registro.

| Partícula | Registro | Termina en vocal | Termina en consonante |
|-----------|----------|------------------|------------------------|
| 와 / 과 | formal, escrito | **와** | **과** |
| (이)랑 | coloquial, hablado | **랑** | **이랑** |
| 하고 | neutro, sirve para ambos | **하고** | **하고** |

**Ejemplos (originales):**

| Coreano | Español |
|---------|---------|
| 사과**와** 배 | manzana y pera (formal) |
| 커피**랑** 빵 | café y pan (coloquial) |
| 김밥**하고** 라면 | gimbap y ramen |

**Como "con" (compañía):** se suele acompañar de 같이 o 함께 ("juntos").
- 친구**하고 같이** 영화를 봐요. → Veo una película **con** un amigo.
- 가족**과 함께** 여행을 가요. → Viajo **junto con** mi familia.

**Regla importante:** no se pueden **mezclar** distintas partículas en la misma lista.
- ✅ 딸기**와** 바나나**와** 사과를 좋아해요.
- ✅ 딸기**랑** 바나나**랑** 사과를 좋아해요.
- ❌ 딸기**와** 바나나**랑** 사과를 좋아해요. (mezcla → incorrecto)

## Resumen rápido (para pizarra)

| Función | Partícula | Vocal | Consonante |
|---------|-----------|-------|------------|
| Sujeto | 이/가 | 가 | 이 |
| Tema / contraste | 은/는 | 는 | 은 |
| Objeto | 을/를 | 를 | 을 |
| "Y" / "con" (formal) | 와/과 | 와 | 과 |
| "Y" / "con" (coloquial) | (이)랑 | 랑 | 이랑 |
| "Y" / "con" (neutro) | 하고 | 하고 | 하고 |
