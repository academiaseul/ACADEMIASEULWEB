## 1. Palabras nuevas · 배워 봐요

| 한국어 | Español |
|---|---|
| 커요 | es grande |
| 작아요 [자가요] | es pequeño, es chico |
| 재미있어요 [재미이써요] | es entretenido, divertido |
| 재미없어요 [재미업써요] | es aburrido, fome |
| 맛있어요 [마시써요] | está rico, es sabroso |
| 맛없어요 [마덥써요] | está malo (de sabor) |
| 길어요 [기러요] | es largo |
| 짧아요 [짤바요] | es corto |
| 뚱뚱해요 | es gordo (en clase: solo animales) |
| 날씬해요 | es delgado, esbelto |
| 코끼리 | elefante |
| 어때요? | ¿qué tal es?, ¿cómo es? |
| extra: 기린 · 코 · 목 | jirafa · nariz, trompa · cuello |

**La frase de hoy: ___이/가 어때요?**
- Termina en consonante (받침) → **이**: 라면**이** 어때요?
- Termina en vocal → **가**: 김치**가** 어때요?
- Se responde sin 이에요: 커요 ya significa «es grande».
- Lo contrario: cambia 있어요 por 없어요 (재미있어요 → 재미없어요), todo junto.
- Lo que ves ahora, 이/가: 코끼리**가** 정말 커요!
- En general o comparando, 은/는: 서울**은** 커요. 우리 동네**는** 작아요. (동네 = barrio)

Lee la situación y responde en coreano.

1. (Un café aguado y quemado que nadie se termina) 커피가 어때요? → ______________________

3. (Un perrito chiquitito) 강아지가 커요? → 아니요, ______________________
4. (Una jirafa) 기린은 목이 짧아요? → 아니요, ______________________
5. (Tu comida favorita) ______________이/가 어때요? → ______________________
6. (Una serie de 16 capítulos en la que no pasa nada) 이 드라마가 어때요? → ______________________

### Ejercicio 3 · ¿Cuál es la pregunta? (repaso de todo el libro · 종합 연습)

Escribe la pregunta para cada respuesta. En la 1 a la 4, pregunta por la parte en **negrita**.

1. ______________________________? — **오늘 저녁에** 사진을 찍어요.
